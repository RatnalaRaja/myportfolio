# Ratnala Raja — Portfolio

> **Associate Software Engineer • Tricon Infotech, Bangalore**  
> Editorial developer portfolio inspired by Ajay Bobbili's design language, featuring an interactive 3D hero avatar with real-time perspective parallax, an interactive Periodic Table of Skills, accordion project showcases, career timeline rail, honours carousel, and certifications registry.

---

## 🎨 Design System & Aesthetic

- **Editorial Typography**: Pairing **Space Grotesk** for clean sans-serif geometry, **Playfair Display** for high-contrast italics, and **Inter** for legible body text.
- **Warm Minimalist Palette**: Contemporary stone/off-white background (`#edecea`), crisp card surfaces (`#f4f3f1`), subtle hairline borders (`#dfded9`), and deep charcoal text (`#111111`).
- **Smooth Micro-Interactions**: Dynamic hover transitions, glassmorphic floating pills, responsive horizontal drag/scroll tracks, and smooth scroll reveal animations.

---

## 💻 Local Development Setup

To preview and run locally:

```bash
# Using Python built-in server
python3 -m http.server 8080

# Or using Node npx serve
npx serve .
```

Open `http://localhost:8080` or simply open `index.html` directly in any modern browser.
