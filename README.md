# Ratnala Raja — Interactive 3D Developer Portfolio

> **Associate Software Engineer • Cloud & AI Architect**  
> Dynamic 3D WebGL Portfolio featuring real-time perspective tracking, interactive developer terminal, AWS & GenAI project showcases, and responsive dark void aesthetics.

---

## 🚀 Key Highlights & Features

- **Interactive 3D Character Card**: Real-time cursor perspective tracking & Euler angle tilt with audio greetings.
- **Three.js WebGL Particle Void**: Dynamic deep-space particle field with interactive cursor light and smooth damping at 120 FPS.
- **Interactive Unix Developer Terminal**: Fully functional browser terminal supporting custom commands (`help`, `skills`, `projects`, `exp`, `certs`, `contact`, `clear`, `whoami`, `cat cv`).
- **Interactive Projects Showcase**: Categorized filter tabs (All, Cloud & DevOps, GenAI / LLM, Full Stack), live demo links, architecture highlights, and impact metrics.
- **Skills Matrix & Architecture Diagram**: Interactive cloud architecture viewer and skills breakdown spanning AWS, Python, FastAPI, Docker, Kubernetes, LangChain, and React.
- **Career Journey Timeline**: Interactive experience timeline at Tricon Infotech and educational background at KL University.
- **Optimized Performance**: Pure Vanilla CSS and JavaScript with modular Three.js for fast load times and cross-device responsiveness.

---

## 🛠️ Tech Stack

- **Frontend Core**: HTML5, Vanilla CSS3 (Custom Glassmorphism, CSS Variables, 3D Transforms), JavaScript (ES6+ Modules)
- **3D Graphics & Animations**: Three.js, WebGL, Web Audio API

## 💻 Local Development Setup

To run locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/RatnalaRaja/myportfolio.git
   cd myportfolio
   ```

2. **Serve with any static file server**:
   ```bash
   # Using Python
   python3 -m http.server 8080

   # Or using Node npx serve
   npx serve .
   ```

3. Open `http://localhost:8080` in your browser.
